# Third-party and asset notes

Dependencies are installed, not vendored. Review upstream licenses for Manim, manim-voiceover, PyMuPDF, python-pptx, FFmpeg, PyTorch and optional MLX packages. Operating-system fonts/voices are not redistributed.

LiquidAI LFM3-Audio and Fish Audio carry separate model licenses and usage restrictions. Review the license accompanying the exact checkpoint. A license for this code would not relicense models, recordings, slides or generated material. Pinned upstream modeling code can execute when a model is loaded; review it before enabling it.

Only self-authored source examples are included. Reference recordings, audition measurements and prior course documents are excluded from distribution. Fish users must supply an authorized reference clip/transcript or create their own preset. Built-in LFM3 presets use locale/gender/seed without bundled audio.
